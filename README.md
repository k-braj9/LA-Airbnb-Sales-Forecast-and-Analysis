# LA-Airbnb-Sales-Forecast-and-Analysis
- This project was an analysis of AirBnB listings in Los Angeles to uncover pricing trends, identify price change factors, and build predictive models for pricing

# Data
- This dataset contains listing information of Airbnbs in Los Angeles
- Information includes:
     - Listing Price
     - Neighborhood
     - Room Type
     - Number of bedrooms
     - Review Scores
     - Availability
     - Minimum Nights      


# Tech Stack
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

# ML Workflow
- I build an ARIMA forecasting model in order to make predictions based on certain characteristics
- First Step: Clean the data and handle missing values using pandas
- Second Step: Preprocess data and divide sets using train/test split method
- Third Step: After training model, evaluate performance based on predictions. Analysis includes values such as MAE and R2

# Results
- After analysis ran on Jupyter Notebook, its determined that characteristics such as location, room type, and listing activity, and seasons are the highest influencers of LA Airbnb prices
